# Portafolio personal

Portafolio web desarrollado con React para presentar mi experiencia profesional, proyectos, habilidades y certificaciones en
un formato web interactivo y responsive.

## Tecnologías

- React
- Vite
- CSS
- GitHub

## Características

- Diseño responsive
- Sección de presentación y experiencia profesional
- Visualización de proyectos
- Sección de habilidades y tecnologías
- Visualización de certificaciones
- Carruseles de imágenes
- Modales para visualizar certificados
- Descarga del CV en formato PDF

## Ejecución local

```bash
git clone <repositorio>
cd <proyecto>
npm install
npm run dev
